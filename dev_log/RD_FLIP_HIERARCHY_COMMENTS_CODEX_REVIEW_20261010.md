## 2. 必须修正的测试定义

### C1 [P2] B2.2 比较的是解析基线校正后的重构，不能直接等同于原 P1 场差

位置：测试规范 108–113 行。

令 `I_X` 为网格 X 上的 P1 插值，节点误差为 `e_X = rho_X − rho_exact|nodes_X`。实际离散场满足

```text
I_A rho_A − I_B rho_B
  = I_A e_A − I_B e_B
    + I_A(rho_exact|nodes_A) − I_B(rho_exact|nodes_B).
```

规范遗漏了最后两项之差。可以定义 `rho_tilde_X = rho_exact + I_X e_X`，此时它提出的指标确实等于 `||rho_tilde_A − rho_tilde_B||_1`；这是有用的、解析基线校正后的诊断，但改变了原来的重构定义。

**可复现反例。** 单位方形四角精确采样 `rho_exact=1+xy`，沿两条不同对角线剖分。两者节点误差都为零，拟议指标为零；实际 P1 场在中心相差 0.5，整个方形的 L1 差为 1/6。1024² 中点积分得到 0.1666669846。这个局部反例足以否定所声称的恒等式，并不表示 Yee 已经有同样大的误差。

另一个独立问题是“小振幅 e ⇒ 插值误差很小”的推断。`e″` 没有由振幅控制。取周期函数 `e_h(x)=10^-3 cos(pi*x/h)`，h=1/16、1/32、1/64：每种网格的自节点插值误差均为零，但四分之一单元处误差始终约 2.0711e-4。自节点回插只是插值的基本性质，不能证明离节点误差小于待测信号。

**建议。** 保留自己的节点/坐标上的解析误差作为主指标。若采用误差场插值，明确标成上述校正重构，并同时报告原 P1 重构的场差和解析插值基线差。共同网格用 256²/512²/1024² 等做积分分辨率检查，要求积分变化小于测量信号；另外用离节点的已知函数检查插值程序。两项检查用途不同。

### C2 [P2] lazy 的真实连接不能由末坐标重新 Delaunay 化来代替

位置：测试规范 98、110、114 行；实现见 `residual_distribution_solver.c:4046–4114`。

lazy 会保留 registry 中仍有效、但已非当前 Delaunay 的旧三角形。B2.2 对每个末态重新调用 Delaunay，便可能更换 lazy 数值解实际使用的 P1 基底。即使修正 C1，仍不能把该重构直接称为 solver 的真实场比较。相同节点在不同对角线上的反例也说明连接本身可以影响结果。

**建议。** 在共同闭合输出时保存实际 registry 的 CCW 顶点 ID、周期像/展开坐标与时刻，并用该连接重构。当前 `RD_OUTPUT_DIAGNOSTICS` 的 live Delaunay 输出不能自动替代 registry 输出。若暂用重新剖分，只能明确标为共同后处理规则下的节点数据比较。

此外，(iii) interval equal + lazy 与 (ii) equal-step transfer 的差同时含有 interval 事件/transfer 次序和 lazy 的影响。若要单独评价 lazy，应加入 `interval equal, mode 1, no lazy` 对照。原本的 B1.1 与 B1.5 已有类似的成对设计。

### C3 [P2] 调低 lazy 阈值并不构成“必然发生翻转”的故障注入

位置：测试规范 B1.8，75 行。

`MIN_ANGLE=0.5`、`DELAUNAY_EXCESS=179` 只让重连更迟。代码仍会在最小角小于正阈值时采用新连接；实际轨迹也未必造成倒置。因此 KH/随机均匀态完全可能合法完成。把“必须终止”写成这组任意流动算例的通过条件，会把没有产生故障的运行误判为 guard 失效。

**建议。** 将这项拆成阈值压力测试和确定性的几何负对照。后者应给定线性顶点轨迹，并独立确认区间内 signed area 的最小值非正，再测试 production 检查是否拒绝它；另给有效轨迹的正对照。

一个能检查区间内部极值、且比仅检查端点/中点更严格的 fixture 是

```text
x0(s)=(0,0), x1(s)=(s−0.2,0), x2(s)=(0,s−0.3), 0 <= s <= 1.
A(s)=0.5(s−0.2)(s−0.3).
A(0)=0.03, A(0.5)=0.03, A(1)=0.28,
A(0.25)=−0.00125.
```

现有 production 代码 `3917–3933` 已检查面积二次式的区间极小值，逻辑与这个 fixture 相符。本轮仅计算并保存了这个制造例；**没有把它冒充成已执行的 native inversion gate**。

## 3. CFL 档案的独立核验与 early closure 建议

重新核对 `../local_runs/cfl_ledger_gate_20261009_v1/`：1049 个冻结源文件、source tar、两份 binary/Config/IC/参数哈希及档案关联均通过。

- 默认限值 run 的末快照确实到 t=0.005，16384 点，五个保存的快照 rho、p 均为正；日志最大公共闭合守恒误差为 1.246e-14。
- 整个日志的 `cfl_ledger_max` 最大值是 **0.116**，出现在 t=3.90625e-05；Claude 评论 27 行及 log3 §224 所写的 0.103 不是这个全程字段的最大值。该字段混合 live/frozen，不能凭它恢复 frozen-only 最大值。
- 低限值 run 返回非零，确实在 `0.0687702 > 0.05` 时触发 frozen-vertex CFL ledger 的终止消息。
- 这验证的是 guard 的执行与短程默认运行，不是物理限值 1 被超出后的恢复，也不是最终 mode 1 + lazy + natural 的 t=0.05 全程验证。

A.2 的 early closure 值得作为后续方向，但“比值超过 0.8，下个事件闭合”不能直接保证正性。若当前 0.79、下一事件增量为 0.25，就会先跨过 1；分母面积也在变化。这个算术例是缺少前瞻上界的说明，不是已复现的 native 失败。

真正实现时需要在提交更新前约束下一次增量/几何，必要时提前调度或重试；整个 star 的 closure、trace refresh、live 判定与 ledger reset 也须一致。闭合完整元素区间可以保持守恒，并不自动证明 CFL/正性。Claude 已明确它尚未实现，应继续保留这一限定。

## 4. 次要修正与执行判据

- B1.1 的 `CFL ledger <=1` 应限定 **frozen 顶点**；实现明确允许 live 比值达到 1.5，不能拿当前混合最大值直接作为所有顶点 <=1 的 gate。
- B1.3 的“t=.05 前没有 flip”应由当前配置日志中 cavities=0 验证，而非作为隐含前提。
- B2.1 的 `E_ii−E_i` 是有符号的误差范数之差，可能抵消或变号；可以报告增量，不能把它当作两解距离。估算其下降率须检查符号/量级稳定性，并与每个方法自己的误差收敛分开。
- 96² 上一次 dt 减半只能检测时间步敏感性；实际 dt 可能受 CFL 控制，且 dt 改变网格轨迹/连接。记录实际步长与事件；只有结果有充分分离时才解释时间误差是否主导，不能宣称这一对运行已经严格分离时间和空间误差。
- `flip_campaign_checks.py:18–19` 接受 `RD_FLIP_HIGH_MODE=2`，虽然错误消息要求 0/1。本轮实际调用已复现。建议显式检查返回值属于 `{0,1}`；不影响当前已经检查的有效配置。
- `analyze_flip_gates.py:113` 新增的位移未做周期最短像处理。box=10、xA=.001、xB=9.999 时报告 9.998，而最短空间距离为 .002。若指标含义为末态空间位移，应修正；若要测累计轨迹位移则需要 unwrapped 历史。解析 Yee 误差函数自身已有周期处理，不受此项影响。
- 下一轮 driver 应检查实际末时间、公共闭合、所需物理指标与预期失败消息；完成判据不能仅依赖程序返回码。低 CFL native 档案的完成已在本轮额外核验。
